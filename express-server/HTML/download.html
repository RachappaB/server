Usage Research – Rachappa

This experimental application is part of the Data Sunita mission: understanding behavioral patterns behind phone usage and digital impulse.

It helps users observe screen habits, emotional triggers, and usage cycles that contribute to phone addiction.

The goal is not restriction — but awareness. Awareness builds control.
