Android Setup

Installing the APK

  1. Download the APK file using the button above.
  2. Open Settings → Security on your Android device.
  3. Enable "Install from unknown sources" or "Install unknown apps".
  4. Open the downloaded APK file from your Downloads folder.
  5. Tap Install and wait for it to complete.
  6. Launch the app, enter your registered email, and begin tracking.
