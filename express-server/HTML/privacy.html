Privacy Policy

Last updated: January 2026

Overview

Usage Research – Rachappa and the Usage Tracker Extension are research and productivity-focused tools developed under the Data Sunita platform. This policy explains what data is collected, how it is used, and how it is protected.

Information We Collect

The application or extension may collect:

  • Website domain names visited (e.g., example.com)
  • Active time spent on websites or apps
  • Usage timestamps
  • User-provided email address (used as a unique identifier)
  • Device identifier generated for research analysis

We do NOT collect:

  • Passwords
  • Form inputs
  • Personal messages
  • Browsing content text
  • Financial or payment information

How Information Is Used

  • Productivity research
  • Behavioral pattern analysis
  • Usage statistics generation
  • Improving digital well-being insights

Data Storage

Usage data may be securely transmitted to the Data Sunita server and stored in an access-controlled database. Secure communication protocols (HTTPS) are used during transmission. Local storage may be used temporarily to ensure background synchronization reliability.

Data Sharing

Collected data is not sold, rented, or shared with third-party advertisers. Data is used strictly for internal research and analysis purposes.

User Control

Users may stop data collection at any time by uninstalling the application or disabling the extension. Users may request data deletion by contacting the project administrator.

Security

We implement secure server configurations and access control policies to protect stored information from unauthorized access.

Policy Updates

This privacy policy may be updated periodically. Continued use of the application indicates acceptance of the updated policy.

Contact
