Full Policy

Overview

Usage Research – Rachappa and the Usage Tracker Extension are research and productivity-focused tools developed under the Data Sunita platform. This policy explains what data is collected, how it is used, and how it is protected.

Information We Collect

The application or extension may collect:

  • Website domain names visited (e.g., example.com)
  • Active time spent on websites or apps
  • Usage timestamps
  • User-provided email address (used as a unique identifier)
  • Device identifier generated for research analysis

// what we explicitly DO NOT collect

  • Passwords or authentication credentials
  • Form inputs or keystrokes
  • Personal messages or communications
  • Full browsing content or page text
  • Financial or payment information

How Information Is Used

  • Productivity research and behavioural pattern analysis
  • Usage statistics generation for your personal dashboard
  • Improving digital well-being insights and recommendations

Data Storage

Usage data is securely transmitted to the Data Sunita server and stored in an access-controlled database. Secure communication protocols (HTTPS) are used during all transmission. Local storage may be used temporarily to ensure background synchronisation reliability.

Data Sharing

Collected data is not sold, rented, or shared with third-party advertisers. Data is used strictly for internal research and analysis purposes within the Data Sunita platform.

User Control

You may stop data collection at any time by uninstalling the application or disabling the browser extension. You may request complete data deletion by contacting the project administrator at any time.

Security

We implement secure server configurations and access control policies to protect stored information from unauthorised access. All data is transmitted over encrypted connections.

Policy Updates

This privacy policy may be updated periodically. Continued use of the application indicates acceptance of the updated policy. We will update the "last updated" date at the top of this page with any changes.

For questions, concerns, or data deletion requests:
