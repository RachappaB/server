Privacy Policy – Usage Tracker Extension

Last updated: January 2026

Overview

Usage Tracker is a research and productivity-focused browser extension designed to analyze website usage patterns and time spent on websites. This privacy policy explains what data is collected, how it is used, and how it is protected.

Information We Collect

The extension may collect the following data:

  • Website domain names visited (for example: example.com)
  • Time spent actively viewing websites
  • Browser activity timestamps
  • User-provided email address (used only as a unique identifier)
  • Device identifier generated from browser fingerprint data

The extension does NOT collect:

  • Passwords
  • Form inputs
  • Personal messages
  • Browsing content text
  • Financial or payment information

How Information Is Used

Collected data is used strictly for:

  • Productivity research
  • Browsing behavior analysis
  • Usage statistics generation
  • Improving digital well-being insights

Data Storage

Usage data is securely transmitted to the project server at data.sunita.space and stored in a protected database. Local browser storage is used temporarily to ensure reliable background synchronization.

Data Sharing

Collected data is not sold, rented, or shared with third-party advertisers. Data may only be used internally for research and analysis purposes.

User Control

Users can stop data collection at any time by disabling or uninstalling the extension. Users may also request data deletion by contacting the project administrator.

Security

We use secure communication protocols (HTTPS) and access-controlled servers to protect stored information from unauthorized access.

Policy Updates

This privacy policy may be updated periodically. Continued use of the extension indicates acceptance of the updated policy.
